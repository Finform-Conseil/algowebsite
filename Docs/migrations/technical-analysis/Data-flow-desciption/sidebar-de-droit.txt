4. ELEMENTS DE PRESENTATION LOCALE
-----------------------------------

Les elements suivants ne sont pas des donnees metier inventees :

- format francais des nombres et separateur de milliers ;
- format XOF ;
- conversion d'horodatage vers GMT+1 ;
- libelle "Last update at ..." ;
- libelle "Market open", determine par le calendrier de session BRVM ;
- puces, titres, espacement et ordre visuel.

"Market open" n'est donc pas un champ brut de l'action API. C'est un etat
de session presente localement a partir du calendrier de marche.

6. REGLES DE NON-REGRESSION API-FIRST
--------------------------------------

- Ne pas remplacer une reponse API par BRVM_SECURITIES quand l'action API existe.
- Si un champ API manque, afficher N/D ou une absence explicite.
- Les fallbacks catalogue restent limites au mode mock ou a une degradation explicitement
  tracee lorsque l'API est indisponible.
- Toute nouvelle donnee metier doit suivre :
  API -> store API -> repository -> hook -> modele de presentation -> UI.
- Les URLs de endpoints Django gardent leur slash final dans les fichiers API.
- Le repository dedoublonne les requetes d'action en vol avant exposition au hook.
