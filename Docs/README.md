# Docs

Ce dossier est la documentation officielle et le workflow de référence pour les futurs agents/LLM qui implémenteront des fonctionnalités dans ce projet.

## Rôle

- Centralise les décisions de conception, le workflow d'implémentation et les conventions du projet.
- Sert de source de vérité sémantiquement retrouvable pour les futurs LLM.
- Chaque feature à implémenter documente ici son contexte avant / pendant / après.

## Convention

- Utiliser ce dossier comme premier arrêt de documentation avant toute implémentation.
- Décision d'architecture retenue : ce dossier est la source canonique de documentation / workflow pour les futurs LLM.
